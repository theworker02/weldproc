# weldproc

Weld timestamps and proc durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/weldproc/

## Install / run

```bash
git clone https://github.com/theworker02/weldproc.git
cd weldproc
node src/cli.js
node --test
```
